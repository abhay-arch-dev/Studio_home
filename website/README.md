# Studio Stay – 3D design website

This folder is a complete website with two pages:
- `index.html`: Layout B (bed on the left wall, TV and fridge unit facing it)
- `layout-a.html`: Layout A (the saved earlier version)

Each page links to the other from its top menu. Publish both files together.

## View it on your Mac
Double-click `index.html`. It opens in your browser. It needs an internet connection, because the 3D engine (three.js) and the fonts load from public CDNs.

## Publish it later (free options)
- **Netlify Drop:** go to app.netlify.com/drop and drag this `website` folder onto the page. You get a public link in under a minute.
- **GitHub Pages:** create a repository, upload `index.html`, then turn on Settings → Pages → Deploy from branch (main, root).
- **Vercel / Cloudflare Pages:** create a new project and upload this folder. No build step is needed.

## Edit it
Everything is in `index.html`:
- `PLACE` and `BUY` near the top of the script hold the layout table and the shopping list.
- `FIN` lists the furniture finishes, and `PALS` lists the textile colour schemes.
- `VIEWS` holds the camera presets.
